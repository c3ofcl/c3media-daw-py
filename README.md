# マルチトラック音声エディタ（プロトタイプ）

複数の音声ファイルをそれぞれ別トラックとして読み込み、タイムライン上でトリミング・カット・移動し、
最後に1つの音声ファイルへミックスダウン（結合）して書き出せる、最小構成のWebアプリです。
複数人でリアルタイムに同じ画面を見ながら編集できる、簡易的な共同編集(オンライン編集)機能も備えています。

- フロントエンド: HTML / CSS / Vanilla JavaScript
- バックエンド: Python (Flask + Flask-SocketIO + pydub)

## セットアップ

1. Python 3.9以降を用意してください。
2. **ffmpeg** をインストールしてください（pydubが内部で使用します）。
   - macOS: `brew install ffmpeg`
   - Ubuntu/Debian: `sudo apt install ffmpeg`
   - Windows: https://ffmpeg.org/download.html からダウンロードし、PATHに追加してください。
3. 依存パッケージをインストール:
   ```bash
   cd "プロジェクトのカレントディレクトリ"
   pip install -r requirements.txt
   ```
4. サーバーを起動:
   ```bash
   python app.py
   ```
5. ブラウザで `http://127.0.0.1:5000` を開いてください。
   同じネットワーク内にいる他の人は `http://<このPCのIPアドレス>:5000` にアクセスすると、
   同じプロジェクトに共同編集者(閲覧者)として参加できます。

> 共同編集に使うSocket.IOのクライアントライブラリは `static/vendor/` に同梱済みです。
> 一度 `pip install` を済ませてしまえば、**サーバーの起動・LAN内での接続にインターネット接続は不要**です
> （最初のセットアップ時のパッケージ/ffmpegのダウンロードにのみインターネットが必要です）。

## 共同編集(オンライン編集)について

このアプリは「1つのプロジェクトを、その場にいる数人でリアルタイムに共有しながら編集する」
簡易的な共同編集に対応しています。ログイン機能は無く、最初にアクセスして名前を入力した人が
自動的に**ホスト**になります。

- **ホスト**: 最初に参加した人。他の人からの編集権リクエストを承認/却下できるほか、
  いつでも編集権を強制的に取り戻せます。
- **編集者**: 現在「編集権」を持っている、ただ1人のユーザー。タイムラインの編集（アップロード・
  移動・トリミング・カット・削除）ができるのはこの人だけです。ホストは参加時点で自動的に編集者にもなります。
- **閲覧者**: それ以外の全員。画面（トラックの配置など）はリアルタイムに反映されますが、編集操作はできず、
  画面上部の「✋ 編集権をリクエスト」からホストにリクエストを送れます。ホストが承認すると、
  その人に編集権が移り、元の編集者は自動的に閲覧者に戻ります(トークンパッシング方式)。

再生・停止・書き出しは、閲覧者を含め誰でも行えます（現在のタイムラインを見ながら試聴・自分の手元に
書き出すだけなので、プロジェクトの内容そのものは変更しないためです）。

画面上部の「👥 参加者」ボタンを押すと、現在ルームに参加している人の一覧（名前と役割）が
ドロップダウン表示されます。**ホストの場合は、この一覧から直接それぞれの権限を管理できます**：

- 編集者の行には「編集権を外す」ボタンが表示され、押すとその場で編集権を取り戻せます。
- リクエスト中の人の行には「承認」「却下」ボタンが表示されます。
- それ以外の閲覧者の行には「編集権を付与」ボタンが表示され、リクエストを待たずに
  ホストの判断で直接その人に編集権を渡せます。

### 制約・注意点

- 想定しているのはあくまで少人数・同一ネットワーク内などでの簡易的な利用です。ルームは常に1つ
  （複数プロジェクトの並行編集や、ルームを分ける機能はありません）。
- ページを再読み込みすると一度ルームから退出したものとして扱われます。ホストが再読み込みすると、
  その場に残っている別の参加者が自動的に新しいホストになります。
- ブラウザ側の識別はログインではなく匿名トークン（ブラウザに保存）によるものです。

## 使い方

1. 「+ ファイルを追加 ▾」を押すと、2つの追加方法を選べます。
   - **📁 ファイルから追加**: 手持ちの音声ファイル（mp3 / wav / m4a / flac など）を複数選択します。
   - **🎵 デモ音源を追加**: サーバーが自動生成した、著作権フリーの短い試用音源（ドラムビート・
     ベースライン・メロディ・パッド(コード)の4種類）から選んで追加します。外部の音声素材は
     一切使わず、起動時にその場でサイン波やノイズから合成しているので、インターネット接続や
     ffmpeg無しでも使えます。操作感を試したいときや、デモ用に一時的にトラックを用意したいときに
     便利です。
   いずれの方法でも、追加した音声ごとに新しいトラック（行）が作られます。
2. **移動**: クリップ本体をドラッグすると、タイムライン上の開始位置を変更できます。
3. **トリミング**: クリップの左右の端をドラッグすると、再生範囲を非破壊的に調整できます。
4. **カット**: ルーラー（時間軸）をクリックして再生ヘッドをクリップの途中に置き、
   対象クリップを選択した状態で「✂ カット」を押すと、その位置で2つのクリップに分割されます。
5. **削除**: クリップを選択して「🗑 削除」で削除できます。
6. **音量調整**: 各トラックのラベル部分にあるフェーダー（スライダー）で、トラックごとに
   音量を0%〜150%の範囲で調整できます。右側の数値（例: 「100%」）はクリックすると
   直接タイプして入力できます（Enterまたは他の場所をクリックで確定）。どちらの方法でも
   再生中はリアルタイムに反映され、「⬇ 書き出し」時のミックスダウンにも反映されます。
7. **ミュート / ソロ**: フェーダーの左にある「M」「S」ボタンで、トラックごとにミュート（無音化）・
   ソロ（そのトラックだけを聴く）を切り替えられます。いずれかのトラックをソロにすると、
   ソロされていない他のトラックは自動的に無音になります（ミュート状態のトラック同士でも、
   ソロされていれば聴こえます）。無音になっているトラックはクリップが薄く表示されます。
8. **dBメーター**: 再生中、各トラックのラベル部分と、ツールバーの「MASTER」に
   リアルタイムのレベルメーターが表示されます（緑→黄→赤、右にいくほど大きい音量）。
   MASTER側は0 / -12 / -24 / -36 / -48 / -60dBの固定目盛りをバーの下に表示するので、
   数字が絶えず変化して読みにくくなることはありません（トラック側は幅が狭いため、
   同じ位置に目盛り線のみ表示します）。トラック側は各トラックの実際の出力(音量・
   ミュート/ソロ反映後)を、MASTER側は全トラックを合算した最終的な出力レベルを示します。
   停止すると表示は消えます。
9. **再生**: 再生ヘッド位置から全トラックを同時に試聴できます（「▶ 再生」/「■ 停止」）。
10. **ズーム**: ツールバーの「🔍」欄で、横方向（時間軸、H−/H+）・縦方向（トラックの高さ、V−/V+）を
    それぞれ独立に拡大縮小できます。「⛶ 全体表示」を押すと、今あるトラック数と曲の長さがちょうど
    画面に収まるよう自動調整されます。トラックの高さを詰めすぎた場合、ラベル内のM/Sボタンや
    フェーダー・メーターは非表示になり、トラック名だけの簡易表示になります。
    このズームは各自の画面だけの表示設定で、共同編集中の他の人には影響しません。
11. **書き出し（結合）**: 「⬇ 書き出し(結合)」を押すと、現在のタイムライン配置に基づいて
   全トラックをミックスダウンした1つの音声ファイル（WAV/MP3選択可）が書き出されます。
   Chrome / Edge など対応ブラウザでは、書き出し前に保存先（フォルダ・ファイル名）を選択できます。
   Firefox / Safari など非対応ブラウザではブラウザの通常のダウンロード機能で保存されます。
   いずれの場合も、書き出したデータの取得が完了した時点でサーバー上の一時ファイルは自動的に削除されます。

## スマートフォンでの利用について

スマートフォンの画面幅（目安: 760px以下）では、ツールバーが折り返さず横スクロールする
レイアウトに切り替わります。ボタンが画面に入りきらない場合は左右にスワイプしてください。
トラックの並ぶタイムライン部分はPC版と同様、曲の長さに応じて横スクロールします。

## 制限事項（プロトタイプのため）

- 共同編集は簡易的な実装です。ドラッグ中などリアルタイムの途中経過までは他の人に配信されず、
  操作が確定したタイミング（マウスを離した時など）でまとめて同期されます。
- トラック間でのクリップ移動（行をまたぐドラッグ）には対応していません。
- フェードイン/アウトには対応していません（トラック単位の音量調整・ミュート/ソロは対応しています）。
- 保存・再読み込み（プロジェクトファイル化）には対応していません。ページを再読み込みすると編集内容は失われます。
- スマートフォンでの表示は改善していますが、ピンチズームや詳細なドラッグ操作など、
  タッチ操作そのものの最適化（マウス前提の一部操作の置き換えなど）までは行っていません。
- アップロードした元ファイルはサーバー上の `uploads/` に保存されます。トラックの🗑ボタン、または
  「🧹 音源を全削除」から削除できます。
- 書き出し結果はサーバー上の `exports/` に一時的に保存されますが、ブラウザ側での取得が完了すると
  自動的に削除されます（処理が失敗した場合など、まれに残ることがあります）。
- 書き出し時の保存先指定は File System Access API に対応したブラウザ（Chrome / Edgeなど）のみの機能です。
  対応していないブラウザでは、ブラウザの既定のダウンロード先に保存されます。
